# ВОЙ — версия 2

Сайт барного льда ВОЙ на Next.js App Router, React, GSAP и Three.js.

## Запуск

```powershell
npm ci
npm run dev
```

Адрес: http://localhost:3003. На текущем компьютере `node_modules` подключён из соседнего проекта; на другом компьютере зависимости устанавливаются обычным `npm ci`.

```powershell
npm run typecheck
npm run lint
npm run build
npm start
```

## Структура

- `src/app`: маршруты, layouts, metadata, административная часть.
- `src/components/layout`: шапка, меню, звук, футер и переходы страниц.
- `src/components/ui/arrow-link.tsx`: общая ссылка с анимированной стрелкой.
- `src/features/home`: серверная композиция главной, hero-слайдер, лента товаров, фотокомпозиция и орбитальная сцена.
- `src/features/home/product-story`: видеосцена, горизонтальный сторитейл и закреплённый финальный блок; прокрутка главной управляется одним Lenis.
- `src/features/content`: посадочные страницы, якорная навигация, списки с фотографиями, FAQ.
- `src/features/product`: страница продукта, орнамент и секции упаковок.
- `src/features/catalog`, `cart`, `blog`, `inquiries`: каталог, корзина, журнал и заявки.
- `src/lib/motion`, `src/lib/three`: управление прокруткой, анимацией и 3D.
- `src/styles/site`: базовые стили по областям интерфейса; порядок импорта сохраняет каскад.
- `public`: используемые медиа и брендовые SVG.

Страницы и статичный контент остаются Server Components. Состояние слайдеров, звук, жесты, DOM и WebGL находятся в небольших Client Components и hooks. Параметры маршрутов Next.js читаются асинхронно. Шрифт подключается через `next/font/local`.

Корзина хранится локально. Цены и фасовки демонстрационные, оформление заказа отключено. Формы формируют файл заявки; серверной отправки нет. Юридические ссылки — заглушки.

Отключённые секции главной управляются объектом `sections` в `home-page.tsx`.
